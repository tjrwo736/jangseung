# 장승 0.3.2 — 개인 승인과 로컬 기록 보호

[English](release_0.3.2.en.md)

## 업데이트 후 할 일

1. 장승을 설치한 환경에서 `python -m pip install --upgrade jangseung==0.3.2`를 실행하세요. 플러그인 방식이면 플러그인도 같은 버전으로 업데이트하세요.
2. 기존 개인 예외는 자동 이전하지 않습니다. 예외가 필요하면 프로젝트에서 `aeg policy add`로 필요한 항목만 다시 승인하거나, `aeg policy adopt`가 보여 주는 기존 목록을 검토한 뒤 채택하세요. 프로젝트의 예전 일회 승인은 사용하지 않습니다. 팀의 추가 보호 규칙은 별도로 유지됩니다.
3. 설치기를 쓴 프로젝트는 `aeg install`(Codex는 `aeg install --target codex`)로 관리 대상 훅을 갱신한 뒤 `aeg doctor --hooks`로 확인하세요. Codex가 변경된 훅에 대한 신뢰 승인을 요청하면 명령을 검토한 뒤 직접 승인하세요.

## 판정과 기록

- 개인 예외와 일회 승인은 사용자 프로필에 프로젝트별로 저장합니다. 체크아웃에 들어 있는 파일만으로 장승의 보호 범위가 줄어들지 않습니다.
- 프로젝트 상태 디렉터리가 링크 등으로 다른 위치를 가리키는 경우 정책을 읽거나 감사 기록을 쓰지 않습니다. 정상 디렉터리를 복원한 뒤 진단하세요.
- PowerShell 명령에서 경로라고 확정할 수 없는 인자는 감사 기록의 경로 필드에 남기지 않습니다. 기존 장부를 다시 쓰지는 않습니다. 장부를 외부에 공유하기 전에는 내용을 검토하세요.
- 다음 판정에 필요한 세션 표식을 저장할 수 없으면 해당 쓰기를 거부합니다. **감사 로그만 실패했을 때**는 기존대로 판정을 유지하고 실패 사유를 알립니다.
- 마지막 레코드의 줄바꿈이 끊긴 장부는 전체 검증에서도 정상으로 보고하지 않습니다. 검증만으로 파일이 바뀌지는 않습니다.

## 설치와 테스트

- 확인 대기 중 변경된 설정을 발견하면 설치·제거를 중단합니다. 다른 변경을 검토하고 다시 실행하세요.
- 재설치 시 오래된 Codex 검사 목록을 갱신합니다. Claude Code와 Codex 모두 사용자 훅과 그룹을 공유할 때 사용자 훅의 검사 범위를 보존합니다.
- Windows 가상환경에서도 실행기 선택과 상주 프로세스 종료를 검증합니다.

이 릴리스는 호스트 신뢰 설정을 자동으로 변경하지 않으며, 실제 도구 실행 여부와 장승 CLI의 판정은 별개입니다.
